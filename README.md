<!-- ABOUT THE PROJECT -->
## About The Project

This is a scratch repository for testing GitHub plugin and workflow behaviour. The only file currently
committed is an empty `f.txt`, created by the initial `test` commit. There is no application, library or
build configuration here.

It is intentionally minimal. Anything useful that comes out of these experiments is moved to a dedicated
repository instead.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

### Built With

No stack is currently committed. The repository only contains an empty test file.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

Nothing beyond `git`, and only if you want to inspect the repository locally.

### Installation

```sh
git clone https://github.com/Elouahabi-Naoufal/plugin-testing.git
cd plugin-testing
```

<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- USAGE EXAMPLES -->
## Usage

There is nothing to run. The repository is used as a sandbox for testing repository-level behaviour such
as GitHub Apps, workflows and plugin integrations.
